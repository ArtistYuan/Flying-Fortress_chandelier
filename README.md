# “飞行堡垒 Flying Fortress” 吊灯chandelier
它拥有一点工业风格、可调节“侧翼”反光板（扭力铰链实现悬停）、仿磨砂玻璃的质感、8K镜面不锈钢渲染出的科技感、以及可通配1200mmLED灯管（双端进电）；


# 项目简介
这是一盏吊灯，已完成V1.0验证版的制作；
设计风格为现代工业风格，在设计上不刻意隐藏各种结构件，利用各种结构营造风格又不失细节，质感细腻；
